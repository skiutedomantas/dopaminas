# Physiotherapy Website

A website designed and developed for a client in the physiotherapy sector, with a focus on clear communication, intuitive navigation, and a user-friendly experience.

## Overview
The project aims to present the client's services, provide essential information, and make it easy for visitors to learn more about the practice.

## Features
- Clean and responsive design
- Intuitive navigation
- Clear presentation of services and information
- User-friendly experience across devices
- Registering online for consultations

## Built With
- Astro
- Wordpress ( headless CMS )
